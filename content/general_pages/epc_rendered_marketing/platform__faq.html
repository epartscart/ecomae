Automotive Data & Catalog

Partial

Yes
Cross-referencing combines local analog tables, live eparts catalog analogs, and epartscross lookups. Operators maintain crosses via CSV in CP; storefront search expands bidirectional interchange up to six rounds.
Yes

Yes
Punctuated numbers work: dashes, spaces, and dots are stripped so 06H-103-483-D matches 06H103483D. Prefix autocomplete works on price lists; middle-of-number fuzzy matching on the main results page is not implemented today.
Yes
VIN decode uses the Epart autocatalog API, proxied through our tenant-safe catalog API proxy with response caching. External partners can also call our Catalog API action=vin with an API key.
Partial

Yes

Yes

Partial

Yes

Yes
Catalog and supplier price lists refresh continuously without taking the shop offline. Eparts catalog data is fetched live with DB caching; CP price uploads and pyprices cron feed search instantly after import.
No
